# Truy cập DOCTIS từ Internet

Để có URL Vercel hoạt động khi máy tính cá nhân tắt, làm theo hướng dẫn [VERCEL_DEPLOY.md](./VERCEL_DEPLOY.md). Vercel host frontend và API; MongoDB Atlas host dữ liệu trực tuyến.

`doctis.vn` chưa có DNS công khai theo lần kiểm tra trước. Trước mắt chia sẻ URL miễn phí `*.vercel.app` mà Vercel cấp; muốn dùng `doctis.vn` cần đăng ký tên miền và cấu hình DNS sau.

Không tải `backend/.env` lên GitHub hoặc gửi các mật khẩu/connection string trong tin nhắn.
